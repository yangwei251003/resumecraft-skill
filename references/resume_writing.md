# 简历内容生成细则

> 阶段四：generating 专用参考。匹配分析完成后加载。

---

## 一、内容来源规则

- 仅使用「直接匹配项」+「可强调关联项」作为简历正文
- 待补强项绝不进入正文，只放进《学习提升路径》
- 简历中说出来的每一句话都要能指向知识库中的具体条目

---

## 二、自我评价规范（4要素）

必须包含：
1. **真实匹配点说明胜任理由**（不是「我综合素质优秀」，而是「具备[具体能力]，与岗位[具体要求]直接对应」）
2. **能力-需求对应关系**（我的[能力A]对应岗位的[要求A]）
3. **至少1项坦诚的待提升方向 + 具体提升计划**（如「正在系统学习SQL高级查询，预计2周内达到独立完成业务查询的水平」）
4. **谦逊但自信的语气**

提供2-3个不同侧重点的版本供用户选择。

---

## 三、润色规则（8条）

1. **用具体动词开头**：设计 / 搭建 / 推动 / 优化 / 协调 / 复盘 / 主导 / 重构
   - 避免「负责」「参与」「协助」单独撑整句
2. **尽量加入数据**，但只能使用用户自己的数据，不得捏造
3. **确实没数据时用保守但专业的表达**，如：
   - ❌「大幅提升了转化率」→ ✅「完成页面优化并上线，后续迭代中持续跟踪转化数据」
   - ❌「获得用户一致好评」→ ✅「通过用户反馈收集与迭代，完善了功能体验」
4. **主动嵌入岗位高频关键词**，但要自然，不要堆砌
5. **突出与目标岗位最相关的内容**，弱化无关经历
6. **红线**：不写虚假公司、学历、证书、奖项、职位
7. **未掌握但可短期学会的技能**只放入《学习提升路径》，不进简历正文
8. **允许诚实分级表达**：「了解」「基础」「熟悉」「正在系统学习」「具备基础认知」
   - 但不能写成「精通」「熟练」如果实际达不到

---

## 四、模块编排规则（动态选择，非固定模板）

- **哪个模块对当前岗位最有说服力就往前排**
- 应届生：教育经历 + 项目经历靠前
- 有经验者：实习/工作经历靠前
- 简历最后必须留出位置展示证书/荣誉/作品
- 目标是一页A4，所以不是所有模块都放，挑最有说服力的

---

## 五、排版与篇幅要求

### 5.1 篇幅约束
- **严格一页A4**
- 每段经历2-4条bullet
- 避免大段叙述性文字，HR只有6秒
- 删掉所有空泛形容词（「优秀的」「出色的」「卓越的」）

### 5.2 内容整合为JSON

生成完简历内容后，将其整合为 `resume_content_schema.json` 格式，然后调用 `scripts/build_resume.js` 生成Word文档：

```bash
node scripts/build_resume.js content.json 简历-姓名-岗位版.docx [--photo photo.jpg] [--compact]
```

- 文本中的URL会自动变为可点击超链接（GitHub、作品集等）
- 如提供照片路径，证件照会自动嵌入页头右侧
- 生成后**必须转PDF检查页数**，超过一页则精简内容后重新生成
- `--compact` 是最后手段，会缩小所有字号约15%

### 5.3 版式规范（由脚本保证）

| 元素 | 规格 |
|------|------|
| 字体 | 微软雅黑（全局统一） |
| 主色 | 深蓝 #1F3864（专业低调，非鲜艳蓝） |
| 姓名 | 18pt 加粗 深蓝 居中 |
| 联系方式 | 9pt 灰色 居中，底部深蓝横线 |
| 节标题 | 11.5pt 加粗 深蓝，底部深蓝细线 |
| 正文 | 10.5pt 黑色 |
| 日期 | 10.5pt 灰色，右对齐Tab定位 |
| 副标题 | 9.5pt 斜体 灰色 |
| 页边距 | 0.5英寸 = 720 DXA（全部四边） |
| 项目符号 | 悬挂缩进260 DXA |

## 六、同步输出（10项，全部与简历正文分开）

1. 岗位理解与拆解
2. 三分组匹配分析（《匹配分析报告》）
3. 简历优化策略说明
4. **一页式 .docx 简历文件**（由 build_resume.js 生成）
5. 简历纯文本版本（方便粘贴到在线系统）
6. 2-3个可替换的自我评价版本
7. 可替换的核心经历表达版本（关键bullet的不同写法）
8. 面试官可能关注的问题与应对建议
9. 待补强项与学习提升路径（7天+30天计划、推荐资源、AI工具、练手项目）
10. 下一步建议

---

## 七、简历内容JSON生成说明

AI 在生成简历正文后，需产出 `.json` 文件（符合 `assets/resume_content_schema.json` 格式），再调用 `node scripts/build_resume.js <内容json> <输出.docx> [--photo <照片路径>]` 完成排版。

### sections 设计原则：
- **"教育经历"** 用 `entries`（含日期+学校信息+bullets）
- **"实习/工作经历"** 用 `entries`（含公司岗位+日期+副标题+bullets）
- **"项目经历"** 用 `entries`（含项目名+日期+bullets）
- **"技能清单"** 用 `freeform_bullets`（简单列表，分类展示）
- **"荣誉奖项"** 用 `freeform_bullets`（按级别排列）
- **"证书资质"** 用 `freeform_bullets`
- **"自我评价/核心优势"** 用 `freeform_bullets` 或单独作为 summary 字段

### 内容取舍规则（一页约束下的优先级）：
1. 每段经历最多保留 3 条 bullet，最优先展示与岗位直接相关的
2. 贡献度最低的项目经历可以删除或合并同类项
3. 与岗位无关的证书/荣誉不放入简历
4. 如果内容依然超出一页：减少 bullet → 合并条目 → 才考虑 `--compact`
