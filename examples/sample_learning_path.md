## 二、7 天快速补强计划

### Day 1：SQL 基础夯实
- **上午（1.5h）**：《SQL必知必会》第1-5章（SELECT/FROM/WHERE/ORDER BY）
- **下午（1.5h）**：LeetCode SQL 5题练习
- **检验**：能写出带条件筛选和排序的查询语句

### Day 2：SQL 聚合与分组
- **上午（1.5h）**：《SQL必知必会》第6-8章（GROUP BY/HAVING/聚合函数）
- **下午（1.5h）**：LeetCode SQL 5题练习，重点练GROUP BY
- **检验**：能写出按维度汇总并过滤的查询

### Day 3：SQL 多表查询
- **上午（1.5h）**：《SQL必知必会》第9-11章（JOIN/子查询）
- **下午（1.5h）**：LeetCode SQL 5题练习，重点练JOIN
- **检验**：能写出2-3表联查并得出业务结论

### Day 4：SQL 窗口函数
- **上午（1.5h）**：窗口函数教程（ROW_NUMBER/RANK/LAG/LEAD）
- **下午（1.5h）**：LeetCode SQL 5题练习，重点练窗口函数
- **检验**：能写出排名、环比等常见业务查询

### Day 5：SQL 综合实战
- **上午（1.5h）**：牛客网 SQL 实战模块 10题
- **下午（1.5h）**：用自己的项目数据设计3个业务查询场景并实现
- **检验**：能独立设计并实现一个完整的业务分析查询

### Day 6：Power BI 入门
- **上午（2h）**：Power BI Desktop 安装 + 官方入门教程前3章
- **下午（1.5h）**：导入校园二手交易数据，尝试做基础图表
- **检验**：能做出一个包含柱状图、饼图的基础看板

### Day 7：Power BI 看板 + 复习
- **上午（2h）**：完善 Power BI 看板，添加筛选器和交互
- **下午（1.5h）**：复习 SQL 重点题型 + A/B 测试基础概念（1篇科普文章+1个视频）
- **检验**：完成一个可交互的数据看板 + 能说清A/B测试基本流程

## 五、面试前必须掌握的核心概念

| 概念 | 一句话解释 | 典型面试问法 | 推荐回答要点 |
|------|-----------|-------------|-------------|
| DAU/MAU | 日活/月活用户数 | "DAU突然下降了20%，你怎么排查？" | 维度拆解（渠道/版本/地区）→ 对比同期 → 查外部事件 |
| 转化率 | 完成目标行为的用户比例 | "如何提升注册转化率？" | 漏斗分析 → 找最大流失环节 → 提出假设 → 验证 |
| 留存率 | 新用户在一定时间后仍活跃的比例 | "次日留存率和7日留存率哪个更重要？" | 取决于产品类型（工具类vs社交类）→ 说各自意义 |
| A/B 测试 | 随机对照实验 | "设计一个A/B测试需要哪些步骤？" | 确定指标 → 计算样本量 → 随机分流 → 收集数据 → 显著性检验 |
| 指标体系 | 衡量业务健康度的关键指标集合 | "电商的核心指标有哪些？" | GMV/客单价/转化率/复购率/退货率 → 按业务模块组织 |
