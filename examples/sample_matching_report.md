## 一、岗位理解与拆解

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 岗位名称 | 数据分析师（初级/应届生） |
| 公司/行业 | 某中型互联网公司 / 电商 |
| 工作地点 | 示例城市 |
| 经验要求 | 应届生或1年以内 |
| 学历要求 | 本科及以上 |

### 1.2 岗位核心职责

1. **数据提取与报表**（核心）—— 日常取数、清洗、报表制作
2. **指标监控**（核心）—— 搭建和维护业务指标监控体系
3. **用户行为分析**（核心）—— 挖掘增长和留存驱动因素
4. **专项分析报告**（辅助）—— 推动数据驱动决策
5. **跨团队协作**（辅助）—— 与产品、运营合作，参与A/B测试

### 1.3 硬性要求（门槛项）
- 本科学历 ✅（用户满足）
- 统计学/数学/计算机/信管相关专业 ✅（信息管理与信息系统专业，相关）

### 1.4 核心能力要求
- SQL 数据查询能力
- Python/R 数据处理能力
- Excel 高级功能
- 数据可视化工具
- 基本统计学知识

### 1.5 隐性偏好
- 有业务 sense，不只是"取数工具人"
- 能主动发现问题，而不是等业务方提需求
- 能在面试中展示自己的分析项目/作品集
- 电商行业理解或有相关项目经验

### 1.6 高频关键词（ATS 优化）
`SQL` `Python` `数据分析` `用户行为` `数据可视化` `Excel` `报表` `指标监控` `A/B测试` `Pandas` `业务分析`

### 1.7 必备技能 vs 加分技能

| 必备技能 | 加分技能 |
|----------|----------|
| SQL 数据查询 | A/B 测试方法论 |
| Python 数据处理 | 机器学习基础 |
| Excel 高级功能 | 数据分析实习经验 |
| 数据可视化 | 有个人作品集 |
| 基础统计学 | 电商行业理解 |

### 1.8 该岗位真正看重的能力
- **快速准确的 SQL 取数能力**（每天大量时间在写查询）
- **数据敏感度**（能发现异常、看出规律）
- **沟通表达**（让非技术同事理解分析结果）
- **业务好奇心**（不只是执行，而是理解为什么）

### 1.9 面试官筛选简历的关键信号
- 有数据分析实习经验 → 强烈信号
- 简历中有量化成果（"处理了X万条数据""提升了X效率"）
- 有个人项目/作品集链接
- SQL 和 Python 关键字出现

### 1.10 岗位人才画像
- **适合**：数据敏感度高、自学能力强、沟通好、有数据分析项目经验、愿意深入业务
- **不适合**：只喜欢纯技术不想碰业务、不愿意和业务方沟通、对重复性工作完全无法接受

### 2.2 第二组：可强调关联项 🔗

#### 🔗 关联项 #1：日报自动化项目 → 体现"效率提升"和"主动解决问题"
- **原始经历**：实习时写了个Python脚本把日报自动化了
- **岗位需要**：能够优化数据流程、主动发现并解决问题的数据分析师
- **换角度建议**：
  - 原来说法：做了个自动化脚本
  - 建议改为：识别出业务流程中的重复劳动痛点 → 主动设计并落地了自动化解决方案 → 将日报制作时间从2小时压缩至5分钟 → 该流程被运营团队沿用至今
- **改写理由**：突出"问题发现→方案设计→落地→价值量化"的完整能力链，这正是数据分析师的核心素质

#### 🔗 关联项 #2：校园二手交易分析 → 体现"数据分析全流程能力"
- **原始经历**：爬了3000条微信群消息做了个分析
- **岗位需要**：能从数据采集到报告产出的完整数据分析能力
- **换角度建议**：
  - 原来说法：做了个课程项目
  - 建议改为：独立完成从数据采集（3000+条交易数据）→ 数据清洗分类 → 统计分析 → 可视化报告的全流程数据分析项目，识别出5大热门品类和交易高峰时段规律
- **改写理由**：展示从0到1的完整数据分析能力，数据规模具体化，分析结果有业务价值

#### 🔗 关联项 #3：数模竞赛 → 体现"数据建模与团队协作"
- **原始经历**：拿了个数模省二
- **岗位需要**：数据建模思维、在压力下高效产出的能力
- **换角度建议**：
  - 原来说法：全国大学生数学建模竞赛省级二等奖
  - 建议改为：在全国大学生数学建模竞赛中，3天内完成从问题建模→数据分析→模型求解→论文撰写的全流程，获省级二等奖（体现快速学习、高强度产出和数据建模能力）
- **改写理由**：不只是一个奖项名称，而是体现背后展现的能力

### 2.3 第三组：待补强项 ⚠️

#### ⚠️ 待补强项 #1：SQL 高级查询能力
- **缺失能力**：岗位要求"熟练使用 SQL"，用户目前只会基础 SELECT/JOIN 查询
- **重要程度**：⚠️ 必须补（该岗位每天大量时间在写 SQL）
- **当前状态**：基础查询水平，能写 SELECT/JOIN/简单聚合
- **速成学习建议**：
  - LeetCode SQL 50 题（3-5天，每天2小时）
  - 牛客网 SQL 实战模块（7天集中练习）
  - 《SQL必知必会》速读（2天）
- **预估时间**：1-2周可达到独立完成日常查询的水平
- **在当前简历中的应对方式**：
  - 不写"熟练掌握 SQL"
  - 写"具备 SQL 基础查询能力（SELECT/JOIN/聚合），正在系统学习高级查询与性能优化"
  - 在项目中强调用 Python/Pandas 也能做数据处理，展示相邻能力

#### ⚠️ 待补强项 #2：数据可视化工具（Tableau/Power BI）
- **缺失能力**：用户会用 Matplotlib 但没用过专业 BI 工具
- **重要程度**：建议补
- **当前状态**：Python 可视化熟悉，BI 工具零基础
- **速成学习建议**：
  - Power BI 官方入门教程（3天）
  - 用自己的项目数据做一个 Power BI 看板（2天）
- **预估时间**：1周可做出像样的看板
- **在当前简历中的应对方式**：强调 Matplotlib/Seaborn 可视化能力，诚实提及"正在学习 Power BI"

#### ⚠️ 待补强项 #3：A/B 测试方法论
- **缺失能力**：岗位提到参与 A/B 测试，用户不了解
- **重要程度**：可选补（面试可能会问）
- **当前状态**：零基础
- **速成学习建议**：
  - Udacity A/B Testing 免费课程（2天）
  - 看2-3篇经典A/B测试案例分析
- **预估时间**：2-3天了解基础概念和方法论
- **在当前简历中的应对方式**：不写A/B测试。面试被问到诚实地："目前正在学习，了解了基础概念和实验设计方法"

## 四、岗位客观评价

### 4.1 综合评价

| 维度 | 评价 |
|------|------|
| 优点 | 入门门槛适中，成长路径清晰（分析师→高级→数据科学家） |
| 缺点 | 初期大量取数工作可能枯燥；中型公司数据基础设施可能不完善 |
| 成长空间 | 中等偏上，电商数据场景丰富，能接触到用户增长、推荐等热门方向 |
| 薪资发展潜力 | 应届8-12K起步，2-3年后跳槽可到15-25K |
| 工作强度/压力 | 中等，大促期间(双11/618)压力较大 |
| AI替代风险 | 中低风险，简单取数可被AI替代，但业务理解和策略分析短期难以替代 |
| 新人友好度 | 较高，初级岗有明确的学习路径和 mentor 指导 |
| 长期发展 | 电商数据分析是相对成熟的赛道，需求稳定 |
| 行业风险 | 电商行业竞争激烈，中小公司可能面临经营压力 |
